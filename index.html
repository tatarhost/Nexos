GitHub Actions создаёт временную Linux-машину, дообучает выбранную модель методом LoRA и сохраняет результат как ZIP-артефакт.

Для первого запуска оставь distilgpt2. Другие модели могут требовать больше памяти и времени. Одна JSON-строка на пример: {"text":"Текст для обучения модели."} Минимум 2 примера.
Не загружай пароли, личные данные или чужую конфиденциальную переписку. Обучение меняет адаптер модели, а не создаёт интеллект с нуля. На бесплатном CPU runner обучение больших моделей может не поместиться в память.
